{{/* Site-level customisation. The theme calls this from head.html with the Page as context, so translation links are available here. Two things live here: 1. the Workplace English article styles (we-*), kept in one place rather than inlined in every generated article; 2. a language switch that is visible on a phone without opening the sidebar, and that answers to a left/right swipe as well as a tap. */}} {{/* Build the two destinations. A page that has no counterpart in the other language falls back to that language's home page rather than vanishing. */}} {{- $cur := .Language.Lang -}} {{/* Home pages come from the site config, never hardcoded: which language owns the root path is a setting, and hardcoding it sends one language to a 404 the moment that setting changes. */}} {{- $urls := dict -}} {{- range .Sites -}} {{- $urls = merge $urls (dict .Language.Lang .Home.RelPermalink) -}} {{- end -}} {{- if .IsPage -}} {{- $urls = merge $urls (dict $cur .RelPermalink) -}} {{- range .Translations -}} {{- $urls = merge $urls (dict .Language.Lang .RelPermalink) -}} {{- end -}} {{- end -}}
